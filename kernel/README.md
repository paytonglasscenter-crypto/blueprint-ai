# Blueprint AI Kernel

The kernel contains the core rules, principles, definitions, and versioning logic of Blueprint AI.

The kernel is the part of the framework that should remain stable across all business implementations.

## Purpose

The kernel answers:

- What is Blueprint AI?
- What principles govern it?
- What language does it use?
- How are versions created?
- How should humans and AI systems use the framework?

## Kernel Files

- `PRINCIPLES.md` — Core operating principles
- `DEFINITIONS.md` — Shared vocabulary
- `VERSIONING.md` — Version rules and release logic
