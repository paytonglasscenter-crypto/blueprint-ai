# Blueprint AI Versioning

Blueprint AI uses versioned development so humans and AI systems can understand how the framework evolves over time.

## Version Format

Blueprint AI versions use named phases and numeric releases.

Example:

```text
Genesis 0.1
Genesis 0.2
Genesis 0.3
```

## Genesis Phase

The Genesis phase establishes the foundation.

Genesis releases should focus on:

- Constitutional documents
- Repository structure
- Core principles
- Definitions
- First implementation setup
- Case study foundation
- Search and automation architecture

## Commit Messages

Use clear commit messages that include the version and purpose.

Example:

```text
Genesis 0.2: establish repository structure foundation
```

## Release Rule

A version should only be created when the repository gains a meaningful structural, philosophical, operational, or implementation-level improvement.
