## 1. Purpose

This document prepares Payton Glass Center for a controlled handoff to a coding assistant, developer, or AI build agent.

The purpose is to prevent the build agent from guessing, overbuilding, rewriting the strategy, or adding premature systems.

This file should be used before giving the website build to:

- Codex
- Claude
- Abacus AI
- Any coding assistant
- Any developer
- Any future implementation agent

---

## 2. Handoff Principle

The agent is not being asked to invent the business.

The agent is not being asked to design a complete future operating system.

The agent is being asked to build the first approved website version from the existing Blueprint AI strategy documents.

The agent must follow the project documents as the source of truth.

---

## 3. Business Summary for Agent

Payton Glass Center is a working glass art studio and hands-on glass experience center in Louisville, Kentucky.

It offers visitors the chance to experience glassmaking through guided activities, group tours plus activity, torch-based hands-on glass experiences, fused glass workshops, locally made gallery glass, and custom glasswork.

The website must communicate that this is a real working studio, not a generic activity franchise and not only a retail shop.

Group tours plus activity are a major business priority and should be treated as a primary conversion path.

---

## 4. Primary Build Goal

Build the first clean public website for Payton Glass Center.

The site should:

- Clearly explain the business
- Prioritize group tours plus activity
- Explain hands-on glass experiences
- Support inquiries
- Support local SEO
- Support AEO / AI answer readiness
- Be mobile-friendly
- Be fast and simple
- Be easy to expand later

This is a first build, not the final full business system.

---

## 5. Preferred Technical Direction

The preferred technical direction is an Astro-based website.

Use Astro unless the owner explicitly changes the build direction.

### Preferred build characteristics

- Astro-based
- Static or simple hybrid structure
- Clean page routes
- Simple reusable components
- Minimal JavaScript
- Optimized images
- Basic SEO metadata
- Clear inquiry form path
- Easy future expansion
