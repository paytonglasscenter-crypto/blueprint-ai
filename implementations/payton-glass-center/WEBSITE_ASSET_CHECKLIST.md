## 1. Purpose

This checklist identifies the assets needed before the first Payton Glass Center website build is handed to a coding assistant, developer, or AI agent.

The goal is to prevent the build from stalling because of missing photos, unclear business details, weak page priorities, or incomplete contact information.

This file does not create the website.

This file prepares the raw materials needed to build the website cleanly.

---

## 2. Asset Preparation Principle

The first website build should use real business assets whenever possible.

Payton Glass Center is a working glass art studio and hands-on glass experience center.

The website should feel authentic, local, active, and professional.

The asset set should prioritize:

- Real studio photos
- Real hands-on glass experiences
- Real group activity photos
- Real gallery pieces
- Real owner / artist presence
- Real Louisville location clarity
- Real inquiry paths

Avoid generic stock imagery unless there is no other option.

---

## 3. Asset Priority Levels

Assets should be grouped by importance.

### Priority 1 — Required for first build

These assets are needed for the first public version.

- Business name
- Address
- Phone number
- Primary email
- Hours or visit instructions
- Core page copy
- Basic offer descriptions
- Group tour description
- Hands-on experience description
- Contact / inquiry form fields
- At least 5 strong photos
- Basic logo or text-based brand treatment

### Priority 2 — Strongly recommended

These assets will make the first build much better.

- Hero image
- Group tour photos
- Torch experience photos
- Fused glass workshop photos
- Gallery photos
- Finished glass product photos
- Owner / artist working photo
- Studio exterior or entrance photo
- Customer activity photos
- FAQ answers

### Priority 3 — Future improvement

These can be added after launch.

- Professional video
- Edited short-form social clips
- Blog photos
- Press mentions
- Testimonials
- Review highlights
- Full class calendar images
- Deep custom glass portfolio
- Full gallery catalog
- Staff bios
- Downloadable group tour flyer
