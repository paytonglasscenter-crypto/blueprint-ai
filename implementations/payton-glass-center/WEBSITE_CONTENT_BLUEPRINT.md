## 1. Purpose

This document defines the first content blueprint for the Payton Glass Center website.

The goal is to prepare page copy, page sections, search positioning, AI answer readiness, and conversion flow before writing final website copy or building the site.

This is not the final website copy.

This is the content architecture that will later guide:

- Homepage copy
- Offer page copy
- FAQ copy
- Local search content
- AI search readiness
- Inquiry form design
- CRM source tracking
- Website build planning

## 2. Core Website Voice

The website should sound:

- Clear
- Welcoming
- Confident
- Educational
- Artist-led
- Practical
- Local
- Professional
- Hands-on

The website should avoid sounding:

- Overly fancy
- Too technical
- Too vague
- Like only an art gallery
- Like only a craft store
- Like only a tourist attraction
- Like only a classroom

The business should feel like a real working glass studio that knows how to welcome the public.

These experiences are designed for beginners and focus on safe, guided participation rather than independent studio use.

### Section Draft: Flameworking Explanation

Many people call this glassblowing, but much of the work at Payton Glass Center is flameworking. Flameworking uses a torch to heat and shape glass, while furnace glassblowing uses a furnace and larger gathering process.

Using both terms helps customers find the experience while learning the accurate craft language.
