## 1. Purpose

This document defines the recommended first build scope for Payton Glass Center.

The goal is to identify what should be built first, what should wait, and what should not be built yet.

This file prevents the project from becoming too large, too abstract, or too complicated before the core business system is working.

The first build should help Payton Glass Center:

- Explain the business clearly
- Promote the highest-value offers
- Convert visitors into inquiries
- Support group tours
- Improve local search alignment
- Prepare for AI search visibility
- Begin structured inquiry capture
- Prepare for future CRM and automation
- Avoid overbuilding before owner-confirmed data is complete

---

## 2. Core Principle

Build the smallest useful system that improves the business.

Do not build every possible feature.

Do not build advanced automation before the workflow is confirmed.

Do not build ecommerce before the product and fulfillment model are confirmed.

Do not build online booking before pricing, capacity, age limits, schedule rules, and approval rules are confirmed.

Do not build a complex CRM before the inquiry workflow is stable.

First, build the foundation that helps customers understand and contact the business.

---

## 3. First Build Objective

The first build should create a strong public foundation for Payton Glass Center.

Primary objective:

Make it easy for a customer, group organizer, teacher, family, tourist, or event planner to understand what Payton Glass Center is and submit a useful inquiry.

Secondary objectives:

- Strengthen Google Business Profile alignment
- Support Bing Places and Apple Business Connect alignment
- Improve AI search readiness
- Support group tour inquiries
- Explain fused glass workshops
- Explain hands-on glass experiences
- Explain field trips and private events
- Provide clear contact and visit information
- Capture structured inquiry data for future CRM

---

## 5. First Build Should Not Include Yet

The first build should not include:

- Full ecommerce store
- Complex online booking system
- Automatic capacity scheduling
- Full custom CRM
- Advanced AI agent workflows
- Fully automated customer messaging
- Automated payment/deposit system
- Complex product inventory
- Membership system
- Full course platform
- Full class enrollment system
- Customer portal
- Advanced personalization
- Multi-location structure
- Large blog/content library
- Large-scale paid ad funnel

These may become useful later, but they should not distract from the first working system.

- Source page
- Group type
- Organization
- Participant count
- Age range
- Preferred date
- Preferred time
- Message
- Status
- Next follow-up date
- Notes

### First CRM Decision

Choose one:

- Airtable first
- Lightweight CRM first
- Custom CRM later

Use the first website build to capture structured inquiries.

Choose the CRM tool after real inquiry workflow is reviewed.

## 11. First Build AI Search / AEO Scope

The first build should support AI search by making answers explicit.

The site should clearly answer:

- What is Payton Glass Center?
- Where is Payton Glass Center?
- What can visitors do there?
- Does Payton Glass Center offer group tours?
- Does Payton Glass Center offer hands-on glass experiences?
- Does Payton Glass Center offer fused glass workshops?
- Does Payton Glass Center offer field trips?
- What is flameworking?
- What is fused glass?
- Can kids participate?
- Do projects go home same day?
- How do people request a visit or activity?

### Recommendation

Use clear headings, FAQ sections, descriptive page titles, and consistent language across pages.
