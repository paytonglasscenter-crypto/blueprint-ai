## 3. Work Order Status Labels

Use these labels.

### Not Started

No work has been done yet.

### Current State Recorded

The listing has been reviewed and documented before changes.

### Access Needed

Owner/platform access is required.

### Ready for Update

Current state is recorded and recommended changes are approved.

### Submitted

Updates were submitted to the platform.

### Pending Review

Platform is reviewing submitted updates.

### Live

Updates are visible publicly.

### Blocked

Work cannot continue because access, verification, or data is missing.

### Deferred

Valid update, but not needed now.

---

## 4. Priority Labels

### Critical

Incorrect or harmful information.

Examples:

- Wrong address
- Wrong phone
- Wrong hours
- Wrong website
- Incorrect closed/open status
- Duplicate profile confusing customers

### High

Important visibility or conversion updates.

Examples:

- Missing group tours
- Weak description
- Wrong categories
- No hands-on experience language
- Weak photos

### Medium

Useful completeness and trust improvements.

Examples:

- More photos
- Q&A updates
- Posts
- Secondary directories

### Low

Cleanup or optional improvements.

Examples:

- Minor wording changes
- Low-traffic directories
- Additional photos after primary media is complete
