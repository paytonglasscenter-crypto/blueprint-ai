## 1. Purpose

This document assembles the Phase 4 handoff package for the first Payton Glass Center website build.

It identifies the documents, decisions, instructions, limits, and next actions needed before giving the build to Codex, Claude, Abacus AI, a developer, or another AI coding agent.

The purpose is to create a controlled bridge from strategy to technical execution.

This document does not authorize the website build yet.

It prepares the handoff package.

---

## 2. Phase 4 Goal

Implementation Phase 4 prepares the Payton Glass Center website project for a clean first build.

The goal is to make sure the build agent receives:

- Clear business context
- Clear technical direction
- Clear first-build scope
- Clear page structure
- Clear content sources
- Clear feature exclusions
- Clear repository decision
- Clear owner review boundaries
- Clear stopping points

The build should not begin from a vague prompt.

The build should begin from a controlled handoff package.

---

## 3. Business Context Summary

Payton Glass Center is a working glass art studio and hands-on glass experience center in Louisville, Kentucky.

It is a real professional studio where visitors can learn about glass, experience glassmaking, and purchase locally made work.

Important business priorities:

- Group tours plus activity are a primary revenue driver
- Hands-on glass experiences are a core public offering
- The gallery sells locally made glass connected to the studio
- Custom glasswork should be inquiry-based
- Future deeper classes are important but should not overtake the first build
- The business should be represented as authentic, local, professional, and hands-on

The website must not make the business look like a generic activity franchise, generic retail shop, or unsupported ecommerce business.
