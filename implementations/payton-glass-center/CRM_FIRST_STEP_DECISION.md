## 1. Purpose

This document decides the first practical CRM step for Payton Glass Center.

The goal is not to choose the most powerful CRM.

The goal is to choose the simplest reliable system that helps the business track inquiries, follow-ups, bookings, pickups, reviews, and future opportunities.

The first CRM step should support the website inquiry form without creating unnecessary complexity.

---

## 2. Core Principle

Start with the simplest system that prevents lost opportunities.

A CRM is not just software.

It is the business memory system.

For Payton Glass Center, the first CRM step should help answer:

- Who contacted us?
- What are they interested in?
- Did we respond?
- What is the next follow-up?
- Did they book?
- Did the event happen?
- Is pickup required?
- Should we ask for a review?
- Should we follow up later?
- Are they interested in future classes?

Do not overbuild before the inquiry workflow is tested.

---

## 3. CRM Readiness Status

Current status:

**Planning ready, implementation not ready for heavy CRM.**

Why:

## 5. Option 1: Email Only

### Description

All form submissions go to email only.

### Strengths

- Fastest
- Simple
- No new system to learn
- Easy to launch
- Works with almost any form

### Weaknesses

- Inquiries get buried
- Hard to track follow-ups
- Hard to see open opportunities
- Hard to track group tours
- Hard to track pickup
- Hard to measure inquiry types
- Poor automation foundation
- Weak business memory

### Fit for Payton Glass Center

Acceptable only as an emergency temporary setup.

Not ideal because group tours, field trips, workshops, pickups, and reviews need tracking.

### Recommendation

Do not use email-only as the main system unless speed is the only priority.

---

## 6. Option 2: Email Plus Spreadsheet

### Description

Form submissions send an email notification and also save to a structured spreadsheet.

### Strengths

- Simple
- Cheap
- Easy to understand
- Better than email alone
- Creates a record of inquiries
- Can track status and follow-up
- Easy to export later
- Good first CRM bridge
- Works well with website form tools

### Weaknesses

- Manual follow-up management
- Can get messy if not maintained
- Limited relationship tracking
- Limited automation
- Not ideal long-term
- Requires discipline

### Fit for Payton Glass Center

Strong first step.

This is likely the safest first CRM bridge because it captures structured inquiry data without forcing a heavy CRM decision.

### Recommendation

Recommended if the first goal is to launch quickly and avoid lost inquiries.

## 13. Recommended First Step

Recommended first CRM step:

### Email notification plus structured Google Sheet or Airtable

This gives Payton Glass Center:

- Immediate email alerts
- Structured inquiry records
- Simple follow-up tracking
- Source tracking
- Inquiry type tracking
- Basic status management
- Future migration path
- Lightweight CRM readiness
- No heavy software commitment

### Preferred Path

If Mark wants simplest:

**Google Sheet first**

If Mark wants stronger structure:

**Airtable first**

### Provisional Recommendation

Start with:

**Google Sheet first, designed like a lightweight CRM.**

Then migrate to Airtable or CRM after real inquiry workflow is observed.

---

## 14. Why Google Sheet First May Be Best

Google Sheet first is recommended because:

- It is familiar.
- It is fast to set up.
- It does not slow down the website build.
- It can receive form submissions.
- It can track statuses.
- It can be reviewed manually.
- It can be improved before committing to CRM software.
- It allows Mark to learn what actually needs tracking.

This fits the current stage better than a full CRM.

---

## 15. When Airtable May Be Better

Choose Airtable first if Mark wants:

- Better views
- Cleaner records
- Form options
- Linked tables
- Better event tracking
- Better pickup tracking
- Better class interest tracking
- A more database-like system
- Easier future automation

Airtable may become the better second step.

## 19. Follow-Up Workflow

Basic workflow:

1. New inquiry arrives.
2. Email notification alerts the business.
3. Row is added to tracker.
4. Status defaults to New.
5. Mark or staff reviews inquiry.
6. Response is sent manually.
7. Status changes to Responded.
8. Next follow-up date is set if needed.
9. If booked, booking date/activity are added.
10. After event, status changes to Completed.
11. If pickup needed, pickup is tracked.
12. Review request is marked when ready.
