# Blueprint AI Agents

Agents are AI-powered roles that help analyze, build, operate, improve, and teach Blueprint AI businesses.

Future agents may include:

- Business Architect Agent
- Search Surface Agent
- Google Business Profile Agent
- Website Architect Agent
- CRM Agent
- Content Engine Agent
- Automation Agent
- Teaching Agent
- Consulting Agent
- Case Study Agent

Agents must follow the Blueprint AI kernel and serve the business reality before producing digital outputs.
